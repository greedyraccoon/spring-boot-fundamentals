# Spring Boot Fundamentals

A hands-on project to learn and practice core Spring Boot concepts — REST APIs, dependency injection, and layered architecture.

## Tech Stack
- Java 17 + Spring Boot 3
- Maven + Lombok
- Postman for testing

## What's covered
- IoC, DI, and Bean management
- REST API with GET, POST endpoints
- `@PathVariable`, `@RequestBody`
- Controller → Service → Model architecture

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/products` | Get all products |
| GET | `/products/{id}` | Get product by ID |
| POST | `/products` | Add a product |

## Run locally
Clone the repo, open in IntelliJ, and run `FirstwebappApplication.java`. API starts at `http://localhost:8080`.
